# @tupaia/devops

The place where Tupaia devs go to op

Shell scripts for building and deploying Tupaia on a server, and CI/CD. The AWS infrastructure that runs cloud deployments of Tupaia (the gold master AMIs and the `deployment` Lambda) is in the `tupaia-infra` Pulumi stack, at `pulumi/tupaia/infra` in [beyondessential/ops](https://github.com/beyondessential/ops).
